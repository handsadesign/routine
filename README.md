# Routine

週のルーティンを1画面で追うための、単一ファイルの Web アプリ。

**https://handsadesign.github.io/routine/**

- 曜日ごとに配色が変わる（長距離＝深緑 / 軽いラン＝青 / 休足＝土色）
- 予定をタップでチェック、進捗バーと連続達成日数が更新される
- チェック状態は端末の localStorage に保存（サーバーには送られない）
- 矢印・キーボード左右キー・左右スワイプで日を移動

## 予定の書き換え

`index.html` の `var WEEK = [ ... ]` ブロックだけを編集する。月曜始まりの7要素。

| キー | 意味 |
| --- | --- |
| `word` | 画面に大きく出る言葉 |
| `kind` | `"run"` 深緑 / `"easy"` 青 / `"rest"` 土色 |
| `drink` | `true` なら飲む日 |
| `note` | その日の一行 |
| `events` | `["時刻","やること","補足"]` の配列（補足は空でも可） |

編集して commit → push すると、1分ほどで公開ページに反映される。

## iPhone のホーム画面に追加

Safari で上の URL を開く → 共有ボタン → 「ホーム画面に追加」。
アドレスバーなしの全画面で、アプリのように起動する。
