# Routine

いま取り組んでいることを1画面で追うための、単一ファイルの Web アプリ。

**https://handsadesign.github.io/routine/**

## いまの中身：1ヶ月・筋トレチャレンジ

2026-09-14（月）〜 2026-10-11（日）の4週間。足を痛めたため、走るメニューから切り替えたもの。

- ジムは月・水・土の週3回。A日（胸と背中）と B日（肩と脚）を1回ごとに交互、通算12回
- 種目ごとに「使った重さ」を kg で記録できる。次回は前回の重さが目安として出る
- 第3週から1段階上げる合図が出る
- ジムのない日は起床・食事・就寝だけの軽い枠
- 記録は端末の localStorage（キー `routine.gym.v1`）に保存。サーバーには送られない
- 矢印・キーボード左右キー・左右スワイプ・下のカレンダーで日を移動

## 設定を変える

`index.html` の先頭にある3つの定数だけを書き換える。

| 定数 | 意味 |
| --- | --- |
| `START` | チャレンジ開始日（`YYYY-MM-DD`） |
| `WEEKS` | 何週間つづけるか |
| `GYM` | ジムに行く曜日。`0=月 1=火 2=水 3=木 4=金 5=土 6=日` |

種目を足し引きするなら `MENU` の `items` を編集する。1行は
`["種目","セット×回","目安kg","補足"]`。目安kg を `""` にすると重さ欄が出ない（自重・有酸素向け）。

編集して commit → push すると、1分ほどで公開ページに反映される。

## 走るメニューに戻す

チャレンジ前のランニング版は Git に残してある。

```
git show c990252:index.html > index.html
```

走る版の記録は別キー（`routine.v2`）なので、戻せばそのまま残っている。

## iPhone のホーム画面に追加

Safari で上の URL を開く → 共有ボタン → 「ホーム画面に追加」。
アドレスバーなしの全画面で、アプリのように起動する。
